unveränderte Fernseh-Oberfläche im Vollbild mit DualSense öffnet – ohne websrv-Bedienung.

Wie: start.c + start_hbldr.c (abgeleitet aus websrv hbldr.c, GPL-3.0-or-later, siehe fremd/websrv).
  - Die Oberfläche (app/ausgabe/schritt9/eboot.elf = Testversion "nur lesen") ist eingebettet.
  - Start als Vordergrund-App über die VORHANDENE Platzhalter-App /system_ex/app/FAKE00000
    (wird nur nachgesehen; fehlt sie: Abbruch). /system_ex wird nie beschrieben oder eingehängt,
    keine Kachel, kein app.db.
  - Wie bei websrv wird eine laufende App bzw. ein laufendes Spiel vorher beendet.
  - Arbeitsordner der Oberfläche: /data/homebrew/PS5Cleanup (Test; dort liegt die eboot.elf).

Bauen (nur PC):   bash bauen_start.sh   -> ausgabe/starttest.elf, ausgabe/_bauen.log
Auf der PS5:      bash senden.sh        <- NUR NACH CHRISTIANS OK (schickt an Port 9021, Ausgabe ausgabe/ps5_start.txt)
